# Recipe Garden

An interactive Mother's Day gift app: open the cookbook, complete one garden recipe at a time, drag ingredients into the pot, and reveal a memory plus a lesson after each recipe.

## Run locally

This is a static site, so you can open `index.html` directly in a browser.

For a local server:

```bash
npx serve .
```

## Customize

Edit `script.js` to change:

- Recipe names
- Garden ingredients
- The lesson/message shown after each recipe
- The final thank-you message in `index.html`

If you add real meal photos later, replace the generated `mealArt` backgrounds with image URLs or local files.
